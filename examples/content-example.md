# Content Example

This example shows style constraints, not a reusable post.

## Input Notes

- A user noticed a repeated failure pattern in cross-functional planning.
- The user wants a direct, practical tone.
- No company or client details can be disclosed.

## Draft Direction

Write a short post about why planning fails when teams agree on dates before agreeing on assumptions.

## Anti-Slop Checks

- No fake personal confession.
- No invented metrics.
- No "10 tips" structure.
- No engagement-bait question.
- Includes one practical diagnostic question.
