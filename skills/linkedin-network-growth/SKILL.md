# LinkedIn Network Growth

## Operating Rule

Improve relationship quality and strategic relevance. Do not automate volume or encourage spam behavior.

## Workflow

1. Inspect goals, audience, positioning, current network notes, connection acceptance data, DM response data, and constraints from shared context when available.
2. If working inside this repository, load `../../core/network-engine/network-rules.md`.
3. Identify priority relationship categories.
4. Diagnose graph gaps and dormant valuable contacts.
5. Recommend connection, comment, and follow-up strategies.
6. Provide human-reviewed outreach examples only when the user supplies enough context.

## Required Output

- Facts used.
- Assumptions.
- Network diagnosis.
- Priority connection categories.
- Outreach approach.
- Dormant contact strategy.
- Measurement plan.
- What needs verification.

## Guardrails

- Do not produce mass DM campaigns.
- Do not create fake personalization.
- Do not scrape private contact data.
- Do not treat connection count as the primary goal.
