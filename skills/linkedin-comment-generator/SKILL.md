# LinkedIn Comment Generator

## Operating Rule

Comments must add value to the discussion. Avoid shallow praise, generic agreement, and fake personalization.

## Workflow

1. Inspect the source post, target relationship context, user's point of view, tone, audience, networking goals, and any constraints from shared context when available.
2. If working inside this repository, load `../../core/authenticity-engine/authenticity-rules.md` and `../../core/network-engine/network-rules.md`.
3. Determine the comment purpose: add insight, ask a precise question, contribute an example, clarify a trade-off, or deepen a relationship.
4. Draft concise options that sound human and specific.
5. Mark any claim that requires user verification.

## Required Output

- Facts used.
- Comment objective.
- Draft comment options.
- Relationship note when relevant.
- What needs verification.

## Guardrails

- Do not generate spam comments at scale.
- Do not flatter generically.
- Do not pretend to have read, used, or experienced something not provided.
- Do not use manipulative engagement tactics.
