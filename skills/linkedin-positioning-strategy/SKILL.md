# LinkedIn Positioning Strategy

## Operating Rule

Positioning must be specific, evidence-backed, and aligned with the user's goals. Avoid broad labels that any professional could claim.

## Workflow

1. Inspect profile, goals, audience, tone, prior positioning, and proof points from shared context when available.
2. If working inside this repository, load `../../core/positioning-engine/positioning-rules.md` and `../../templates/positioning-report.md`.
3. Identify current professional identity and expertise clusters.
4. Test for contradictions between headline, About, experience, content, and target audience.
5. Generate multiple positioning options only when there are real trade-offs.
6. Recommend one direction or state what evidence is missing.
7. Map positioning implications to profile sections, content pillars, and network strategy.

## Required Output

- Facts used.
- Current positioning diagnosis.
- Expertise clusters.
- Differentiators.
- Proof points.
- Positioning options with trade-offs.
- Recommended positioning statement.
- Profile changes needed.
- What needs verification.

## Guardrails

- Do not copy competitor language.
- Do not over-niche without checking user goals.
- Do not claim expertise without visible or user-provided proof.
- Do not create contradictory multi-identity positioning.
