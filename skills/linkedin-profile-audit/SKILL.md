# LinkedIn Profile Audit

## Operating Rule

Audit only from evidence provided by the user or available in the repository context. Do not invent profile sections, metrics, achievements, or missing data.

## Workflow

1. Collect or inspect profile evidence: headline, About, experience, Featured, banner, skills, recommendations, certifications, and activity notes.
2. Read relevant shared context when available: profile, positioning, audience, goals, tone, analytics, and SSI history.
3. If working inside this repository, load `../../core/profile-parser/profile-evidence.md` and `../../templates/profile-audit.md`.
4. Separate exact profile text from interpretation.
5. Evaluate:
   - clarity of professional identity;
   - keyword consistency;
   - expertise specificity;
   - audience relevance;
   - authority signals;
   - proof density;
   - section completeness;
   - coherence with stated goals.
6. Prioritize recommendations by impact and confidence.

## Required Output

- Facts used.
- Assumptions.
- Strengths.
- Weaknesses.
- Missing sections.
- Keyword gaps.
- Clarity problems.
- Credibility issues.
- Optimization suggestions with priority.
- What needs verification.

## Guardrails

- Do not recommend keyword stuffing.
- Do not exaggerate credentials.
- Do not rewrite the profile into a generic personal brand.
- Mark incomplete profile data as incomplete instead of treating it as absent.
