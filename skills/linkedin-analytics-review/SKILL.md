# LinkedIn Analytics Review

## Operating Rule

Analytics review must separate observed change from interpretation. Do not claim causation without evidence.

## Workflow

1. Inspect baseline period, current period, analytics exports, content history, profile changes, SSI history, network history, memory records, and experiment notes from shared context when available.
2. If working inside this repository, load `../../core/analytics/metrics.md` and `../../templates/analytics-report.md`.
3. Compare periods and identify meaningful deltas.
4. Evaluate engagement quality, not only volume.
5. Review experiments against hypotheses.
6. Recommend next experiments or strategy changes.

## Required Output

- Facts used.
- Baseline and current periods.
- Metric deltas.
- Pattern detection.
- Experiment review.
- Recommendations.
- What needs verification.

## Guardrails

- Do not invent missing analytics.
- Do not overinterpret small samples.
- Do not optimize for likes alone.
- Do not hide uncertainty when data is incomplete.
