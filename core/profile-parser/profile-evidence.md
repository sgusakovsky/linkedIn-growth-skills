# Profile Evidence

Use this reference when extracting profile information from user-provided text, screenshots, exports, or manual notes.

## Extract

- headline;
- About section;
- experience roles and achievements;
- Featured section items;
- skills;
- recommendations;
- certifications;
- services or creator topics;
- visible audience and activity signals.

## Evidence Rules

- Distinguish exact profile text from interpretation.
- Do not invent missing achievements or metrics.
- Preserve user wording when auditing tone.
- Mark screenshots or partial copies as incomplete.
- Ask for missing sections only when needed for the requested task.

## Risk Flags

- unclear professional identity;
- broad claims without proof;
- mismatched headline and experience;
- repeated keywords with no evidence;
- outdated roles;
- missing featured proof;
- unclear target audience.
