# Benchmark Rules

Benchmarking compares patterns without cloning another profile.

## Compare

- positioning clarity;
- authority signals;
- proof density;
- content themes;
- engagement quality;
- network strategy signals;
- profile completeness;
- audience fit.

## Rules

- Extract patterns, not copy.
- Separate observed facts from inferred strategy.
- Note where data is incomplete.
- Highlight white space the user can credibly own.
- Avoid making the user interchangeable with stronger profiles.
