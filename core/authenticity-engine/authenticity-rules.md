# Authenticity Rules

Use this reference for posts, comments, profile copy, and recommendations.

## Enforce

- real experience anchors;
- concrete examples;
- practical insight;
- natural rhythm;
- domain-relevant language;
- user-specific constraints and goals;
- humility about uncertain claims.

## Avoid

- fake storytelling;
- fake emotional hooks;
- fake vulnerability;
- engagement farming;
- generic leadership language;
- motivational spam;
- repetitive listicles;
- exaggerated thought-leader phrasing;
- overuse of emojis;
- claims the user has not supported.

## Authenticity Check

Before finalizing any draft, ask:

- What exact user evidence supports this?
- Could any competent person in the field have written the same thing?
- Does it sound like a person with lived context or a generic content system?
- Is the hook truthful and proportional?
- Is the takeaway useful without begging for engagement?
