# Evaluation Rubric

Use this framework to evaluate LinkedIn growth work.

## Dimensions

| Dimension | Question |
| --- | --- |
| Clarity | Can the audience quickly understand who the user helps and why they are credible? |
| Differentiation | Is the user distinct without becoming artificially narrow? |
| Evidence | Are claims supported by visible proof or user-provided facts? |
| Authenticity | Does the output sound grounded in real experience? |
| Audience Fit | Does it speak to the right people in their language? |
| Reputation Safety | Does it avoid spam, exaggeration, and cringe patterns? |
| Outcome Alignment | Does it support the user's career or business goals? |
| Learning Loop | Does it create measurable experiments and update future strategy? |

## Scoring

Use low, medium, or high confidence. Explain what would raise confidence.

## Final Review

Every strategic recommendation should state:

- expected benefit;
- evidence used;
- risk;
- measurement plan;
- user decision required.
