# Positioning Rules

Use this reference when defining or reviewing a user's professional positioning.

## Good Positioning

Good positioning is specific enough to be remembered and broad enough to support the user's real goals.

It should include:

- professional identity;
- target audience or problem area;
- expertise clusters;
- differentiators;
- evidence and proof points;
- language the audience recognizes.

## Avoid

- generic labels without proof;
- contradictory expertise signals;
- claims that outrun evidence;
- overly broad branding;
- trend-chasing that conflicts with the user's history;
- copying competitor language.

## Output

Provide:

- current positioning diagnosis;
- strongest credible positioning options;
- trade-offs between options;
- recommended positioning statement;
- profile sections that must change to support it;
- open questions that block stronger confidence.
